# Панель поиска KirVPN

Веб-панель: поиск пользователя, остаток дней и трафика, число пользователей, оповещение в приложение, проверка доступности с российских узлов. На сервере она лежит в `/opt/kirvpn-find` и слушает `127.0.0.1:18765` (снаружи её открывает nginx).

В этот каталог попали исходники страниц и логика. Живые адреса, ключ SSH, пароль входа в панель, ключ Hostup и тексты оповещений сюда не входят: репозиторий публичный.

## Что показывает какие цифры

Поиск, расширенный поиск, остаток дней, потраченный и оставшийся трафик пользователя, счётчик пользователей читают базу `hiddifypanel` на **ориджине**. Адрес берётся из `nodes.json`: у каждой записи есть `label` (номер сервера) и `ip` (IP ориджина, не релея).

Вкладка тестирования читает `fleet.json`: ориджин, реле, имя подписки, как идёт трафик (`rf_direct` или `origin`).

Вкладка трафика машин Hostup ходит в API Hostup по файлу `hostup.key`. Это расход VPS у провайдера, не трафик пользователей Hiddify.

## Что нужно, чтобы цифры остались после переноса

Пароль root и пароль панели сюда присылать не нужно. Текущая программа **не** ходит в API Hiddify. Она заходит на ориджин по SSH как `root` ключом `id_ed25519` и выполняет локальный `mysql` без пароля в команде.

На каждом новом ориджине должно быть так:

1. В `nodes.json` записан новый IP этого сервера. Пока там старый адрес, поиск и остатки смотрят на старую машину.
2. `root` пускает ключ, который уже лежит на сервере панели (`/opt/kirvpn-find/id_ed25519`). Новый ключ генерировать не нужно: тот же публичный ключ добавляется в `/root/.ssh/authorized_keys` новой машины.
3. На машине установлена Hiddify, база называется `hiddifypanel`, и `mysql -N -e 'SELECT 1'` под root выполняется без пароля.
4. Для вкладки тестирования в `fleet.json` обновлены `origin`, `rf_ips`, `rf_ssh` и `sub_host`, если имя подписки изменилось.

Файлы `nodes.json` и `fleet.json` правятся на сервере панели. Образцы без настоящих адресов: `nodes.example.json`, `fleet.example.json`.

## Если вместо SSH будет API Hiddify

Этого достаточно, чтобы **прочитать** пользователей и их трафик, без пароля сервера:

- адрес `https://домен/<путь_админки>/api/v2/admin/`
- заголовок `Hiddify-API-Key`: UUID супер-админа из раздела API панели

Обычный ключ пользователя для этого не подходит. Этот снимок программы API не вызывает. Ключ имеет смысл, если панель поиска позже переведут с SSH на API. Пока ключ не заменяет пункт про `nodes.json` и SSH.

API не меняет DNS и не записывает новый IP панели. Смена A-записей `kirvpn.us`, `kirvpn.ru`, `sarafan.uk` делается отдельно в Cloudflare.

## Запуск

Рядом с кодом на сервере должны лежать файлы, которых нет в git: `id_ed25519`, `htpasswd`, `session.key`, `nodes.json`, `fleet.json`. Для трафика Hostup ещё `hostup.key`. Для списка машин, которые надо скрыть, `excluded-ips.txt` (см. пример).

Служба: `kirvpn-find.service`. После правки Python-файлов её перезапускают: `systemctl restart kirvpn-find`.
