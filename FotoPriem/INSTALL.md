# Как поставить Фотоприём на iPhone в первый раз

Кода на твоём Mac ещё нет, пока ты его не скачаешь. Xcode сам из GitHub ничего не подтягивает. И открывать нужно не папку, а файл проекта **FotoPriem.xcodeproj**.

Ниже путь «скачал ZIP → открыл в Xcode → нажал Play». Git для этого не обязателен.

---

## Что должно быть заранее

1. **Mac** (не Windows, не iPad).
2. **Xcode** из App Store: найди приложение «App Store» на Mac → поиск `Xcode` → Получить / Установить. Это долго, несколько гигабайт. Когда установится — открой Xcode один раз и согласись на установку дополнительных компонентов.
3. **Apple ID** (обычная почта Apple). В Xcode: меню Xcode → Settings… → Accounts → `+` → Apple ID. Войди тем же аккаунтом, что на iPhone.
4. **iPhone** и кабель USB.
5. На iPhone и Mac должны быть включены: разблокированный телефон + «Доверять этому компьютеру».

Платный Developer за $99 пока не обязателен: бесплатного Apple ID хватит, чтобы поставить приложение на **7 дней** и проверить. Потом можно оплатить, чтобы жило около года.

---

## Шаг 1. Скачать проект с GitHub

Проект лежит в ветке `cursor/fotopriem-ios-158b`, не в обычном `main`. Если скачать «главную» страницу репозитория — папки FotoPriem там не будет.

Самый простой способ без Git:

1. Открой в браузере:  
   https://github.com/Kirimbay/docs/tree/cursor/fotopriem-ios-158b
2. Зелёная кнопка **Code**.
3. **Download ZIP**.
4. ZIP появится в Загрузках. Дважды щёлкни — получится папка  
   `docs-cursor-fotopriem-ios-158b`.
5. Перетащи её, например, в Документы, чтобы не потерять.

Альтернатива той же ветки одним файлом:  
https://github.com/Kirimbay/docs/archive/refs/heads/cursor/fotopriem-ios-158b.zip

Если умеешь Git: склонируй репозиторий и переключись на ветку `cursor/fotopriem-ios-158b`. На `main` этого приложения нет.

---

## Шаг 2. Найти файл, который открывает Xcode

В распакованной папке иди так:

```
docs-cursor-fotopriem-ios-158b
  └── FotoPriem
        └── Apps
              └── FotoPriem
                    └── FotoPriem.xcodeproj     ← вот этот
```

Как выглядит: синяя иконка вроде чертежа / кирпичиков, имя **FotoPriem.xcodeproj**.

Чего открывать **не надо**:

- не всю папку `docs-…`
- не `FotoPriem` как папку
- не `Package.swift`
- не README
- в Cursor / VS Code «Open Folder» — это другой редактор, не Xcode

---

## Шаг 3. Открыть именно в Xcode

**Вариант А (проще):** в Finder дважды щёлкни `FotoPriem.xcodeproj`. Должен открыться Xcode, сверху в окне будет название **FotoPriem**.

**Вариант Б:** открой Xcode → меню **File → Open…** (не Open Folder). В окне выбора файла дойди до `FotoPriem.xcodeproj` и нажми Open.

Если Xcode спрашивает про дополнительные платформы / iOS SDK — согласись и подожди.

Первый раз индекс проекта может думать 1–2 минуты. Дождись, пока сверху пропадёт «Indexing» / крутилка.

---

## Шаг 4. Подписать приложение своим аккаунтом

Без этого на iPhone не поставится.

1. Слева в Xcode есть список файлов (Navigator). Кликни синюю иконку проекта **FotoPriem** на самом верху.
2. В средней колонке выбери target **FotoPriem** (не папку, а цель под TARGETS).
3. Вкладка **Signing & Capabilities**.
4. Поставь галку **Automatically manage signing**.
5. **Team:** выбери свой Apple ID. Если списка нет — Xcode → Settings → Accounts, добавь Apple ID, вернись сюда.
6. Если Bundle Identifier красный («уже занят»), допиши в конец что-то своё, например `app.fotopriem.FotoPriem.kirill`.

Ошибки вроде *Failed to register bundle identifier* / *Personal development teams* почти всегда лечатся сменой Bundle ID и повторным выбором Team.

---

## Шаг 5. Подключить iPhone

1. Кабелем к Mac. Разблокируй iPhone.
2. Если спрашивает «Доверять этому компьютеру?» — Доверять, введи пароль телефона.
3. На iPhone iOS 16+: Настройки → Конфиденциальность и безопасность → **Режим разработчика** → включи → перезагрузка → подтверди.
4. В Xcode **вверху по центру** (рядом с кнопкой ▶️) нажми на устройство. Сейчас там может быть «FotoPriem > iPhone 16» (симулятор). Выбери **свой iPhone** по имени.
5. Симулятор для FTP с камерой не подойдёт — нужен живой телефон.

Если iPhone серый и пишет *Unlock to enable* — просто разблокируй телефон.  
Если *Developer Mode disabled* — шаг 3.

---

## Шаг 6. Нажать Run и доверить сертификат

1. В Xcode большая кнопка **▶️** слева сверху (или `Cmd + R`).
2. Первая сборка долгая. Жди, пока на iPhone не откроется приложение **Фотоприём**.
3. Если вылезет *Untrusted Developer* / «Ненадёжный разработчик»:
   - iPhone → Настройки → Основные → VPN и управление устройством (или «Управление устройством»)
   - твой Apple ID → **Доверять**
   - снова ▶️ в Xcode

Разреши приложению **Локальную сеть** и **добавление в Фото**, когда iOS спросит.

Готово: иконка Фотоприём на домашнем экране. Кабель можно вынуть.

---

## Если что-то не находится

| Что видишь | Что это значит |
|---|---|
| В Xcode «Open Folder», а папки FotoPriem нет | Ты, скорее всего, в Cursor, не в Xcode. Открой приложение **Xcode** (синий инструмент). Либо ZIP ещё не скачан — см. шаг 1. |
| Репозиторий `docs` открыт, а FotoPriem нет | Открыта ветка `main`. Нужна ветка `cursor/fotopriem-ios-158b`. |
| Открылся README или куча `.md` файлов | Открыт не тот файл. Ищи `FotoPriem.xcodeproj`. |
| Xcode пишет *No Team* / signing error | Шаг 4: Accounts + Team + свой Bundle ID. |
| Приложение ставится и сразу пропадает через неделю | Бесплатный аккаунт. Для постоянной обкатки — Apple Developer Program. |

---

## Что делать после установки

В приложении выбери **Нет связи**, нажми **Запустить приём**, перепиши на камеру IP / порт `2121` / логин `foto` / пароль `priem`. Камера и iPhone должны быть в одной Wi‑Fi сети камеры.
