# Фотоприём

iPhone принимает JPEG, RAW и видео с камеры по FTP и кладёт их в Фото.
Два сценария:

1. **Нет связи** — камера раздаёт Wi‑Fi, iPhone подключается к ней. Яндекс Диск выключен.
2. **Есть связь** — точка доступа iPhone, камера подключается к телефону. Кнопка Яндекс Диска активна.

Проводной импорт и дедупликация специально не делаются.

## Поставить на свой iPhone с Mac

**Подробная инструкция для первого раза:** [INSTALL.md](INSTALL.md)

Коротко: скачай ZIP ветки `cursor/fotopriem-ios-158b` с GitHub, в Finder дважды щёлкни файл `FotoPriem/Apps/FotoPriem/FotoPriem.xcodeproj` (не папку), в Xcode укажи свой Team и нажми ▶️ на подключённый iPhone.

Платный Apple Developer ($99/год) нужен, чтобы сборка жила около года. Без него приложение с бесплатного Apple ID протухнет через 7 дней.

## Как снимать

### Нет связи (основной режим)

1. Включи Wi‑Fi / access point на камере.
2. На iPhone: Настройки → Wi‑Fi → сеть камеры. Предупреждение «без интернета» — это нормально.
3. У этой сети выключи **Частный адрес Wi‑Fi**, иначе IP может прыгать.
4. Открой Фотоприём, сценарий «Нет связи», **Запустить приём**.
5. В FTP камеры пропиши IP / порт `2121` / логин `foto` / пароль `priem`.
6. Снимай. Файлы сразу идут в Фото. Экран лучше не гасить (переключатель включён).

### Есть связь

1. Включи режим модема на iPhone.
2. Подключи камеру к этой сети.
3. В приложении сценарий «Есть связь», запусти приём.
4. IP чаще всего `172.20.10.1`.
5. Кнопка «Выгрузить в Яндекс Диск» становится активной после входа.

Для Яндекса создай приложение на [oauth.yandex.ru](https://oauth.yandex.ru), callback `fotopriem://oauth`, вставь Client ID в приложение и нажми «Войти в Яндекс».

## Стенд без телефона

Ядро FTP собирается на Mac/Linux и прогоняет 50 файлов как камера (JPEG + RAW + видео):

```bash
cd FotoPriem
swift build -c release
python3 Tools/teststand/run_50_photo_test.py --server .build/release/fotopriem-server
```
