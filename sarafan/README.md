# Сарафан v2

Чат с комнатами: ник + пин, номер комнаты из 6 цифр, текст и фото, пуши.

## Запуск

```bash
ADMIN_PASSWORD='секрет' npm start
```

Открой http://localhost:3847

## Супер-админ

На экране входа **зажми** слово «Сарафан» (~0.7с) → пароль `ADMIN_PASSWORD`.

## Роли

- Участник — пишет, реагирует, отвечает
- Владелец комнаты — закрепы, удаление сообщений, ключ/закрытие, удаление комнаты
- Супер-админ — ghost, каталог, удаление чужих комнат

## Проверки

```bash
ADMIN_PASSWORD='секрет' node scripts/role-checks.mjs http://127.0.0.1:3847
```
