# Комната — анонимный чат

Открытый чат без регистрации: случайное или своё имя, текст и фото, закреплённые сообщения для админа.

## Возможности

- Вход без аккаунта
- Случайное имя или своё (до 24 символов)
- Сообщения в реальном времени (Socket.IO)
- Только текст и фото (без аудио/видео)
- Закрепление и удаление сообщений по админ-паролю
- История сохраняется на диске (`data/store.json`), новым участникам доступны последние 5000 сообщений

## Запуск

```bash
cd anon-chat
cp .env.example .env   # по желанию
# задайте свой пароль админа:
# ADMIN_PASSWORD=секрет PORT=3847
npm install
npm start
```

Откройте http://localhost:3847

Для разработки с автоперезапуском: `npm run dev`.

## Админ

1. Войдите в чат как обычно.
2. Нажмите **Админ** и введите `ADMIN_PASSWORD` (по умолчанию `change-me`).
3. У сообщений появятся кнопки **Закрепить** / **Открепить** и **Удалить**.

Права админа действуют до перезагрузки страницы (нужно снова ввести пароль).

## Переменные окружения

| Переменная | По умолчанию | Описание |
|---|---|---|
| `PORT` | `3847` | Порт HTTP |
| `ADMIN_PASSWORD` | `change-me` | Пароль для закрепов и удаления |
| `MAX_UPLOAD_MB` | `5` | Максимальный размер фото |

## Структура

```
anon-chat/
  server.js
  public/          # интерфейс
  uploads/         # загруженные фото
  data/            # store.json (создаётся при работе)
```
