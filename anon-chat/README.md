# Сарафан — анонимный чат

Открытый чат без регистрации: случайное или своё имя, текст и фото, закреплённые сообщения для админа.

## Возможности

- Вход без аккаунта
- Случайное однословное имя или своё (до 24 символов)
- Сообщения в реальном времени (Socket.IO)
- Фото сжимаются в WebP при загрузке
- Закрепление / удаление / «Позвать всех» для админа
- История на диске, последние 5000 сообщений
- Бэкап одним архивом: `deploy/backup.sh` / `deploy/restore.sh`

## Запуск

```bash
cd anon-chat
npm install
ADMIN_PASSWORD=секрет npm start
```

Открой http://localhost:3847

## Админ

1. Войдите в чат.
2. Нажмите **Админ** и введите `ADMIN_PASSWORD`.
3. Доступны закрепы, удаление и кнопка **Позвать** (push всем подписчикам).

## Переменные окружения

| Переменная | По умолчанию | Описание |
|---|---|---|
| `PORT` | `3847` | HTTP-порт |
| `ADMIN_PASSWORD` | `change-me` | Пароль админа |
| `MAX_UPLOAD_MB` | `5` | Макс. размер исходного фото |
| `IMAGE_MAX_PX` | `1440` | Макс. сторона после сжатия |
| `IMAGE_QUALITY` | `68` | Качество WebP |
