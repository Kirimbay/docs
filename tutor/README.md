# Кукузя — добрый репетитор

Интерактивный урок по страницам 24–25 учебника: порядок действий.
Ребёнок нажимает задание, Кукузя объясняет спокойным мужским голосом и показывает шаг на картинке.

Сайт: [кукузя.рф](http://кукузя.рф) (`xn--g1afa9ab7e.xn--p1ai`).

Голос: `ru-RU-DmitryNeural`, скорость `+25%`, тон `+0Hz`.

## Команды

```bash
npm install
npm test
npm run audio
npm run dev
npm run build
```

Новая страница учебника добавляется так: фото кладётся в `public/`, условие и реплики — в `src/content.ts`, картинка шага — в `src/ui/screens.tsx`. После правки реплик снова запусти `npm run audio`.
