## Короткий ответ

**Не обязательно 3 новых сервера.** Достаточно **3 дополнительных IP** на SERV.HOST (~85₽ каждый), повешенных на **три разные уже живые машины**, у которых путь до Hostup 5/5.

Новые VPS берите только если:
- нет свободного слота IP на хороших машинах, или
- хотите изоляцию (один exit — один релей).

## Минимум заказа

1. IP для **exit 60** → новый primary; освободим `144.31.50.159`  
2. IP для **exit 8** → прямой DNAT, снимем WG  
3. IP для **exit 57** → прямой DNAT, снимем WG  

После оплаты пришлите в чат на каждый IP:

```text
exit: 8|57|60
new_ip: x.x.x.x
host_ip: (основной IP машины, куда повесили)
ssh: ключ уже есть / пароль root …
```

Агент: DNAT → probe → DNS → отключить костыль.
